# Android 任务首页与采集任务

记录日期：2026-09-05。本文替代旧的对话首页、单草稿入口、必经整理网格与重拍方案。先记录已决定的行为；实现与验证结果在文末单独维护。

## 已决定的界面与导航

普通业务页面固定蓝白主题，不跟随系统变为深色；只有相机固定蓝黑。关闭动态配色，沿用 Android 专用蓝、红、黄、绿调色板，不影响 XML 或输出文档。

首页顶部按标题搜索，任务按创建时间倒序。每项第一行是最终标题（未生成时为“未命名文档”）及独立的中性“草稿”标签；第二行保持单行 `yyyy-MM-dd HH:mm | 照片图标 数量 | 字数图标 总字数`。时间为创建时间的本地 24 小时制，照片数只计有效页面，最终文档生成前字数为“—”。右下角蓝底白色加号新建。

允许多个草稿，只同时打开一个相机。当前版本允许未连接服务先新建本地任务并进入相机，持续提示“未连接服务器 · 照片保存在本地”；服务端 ID 在后台取得，取得前不上传，不以本地 ID 冒充服务端 ID。已有本地照片不能因网络故障丢失。

相机保留单击大图、双击删除及长按排序；不再提供重拍。返回弹窗提供保存并退出、仅从本机列表移除、继续拍摄。保存保留本地任务 ID、已有的服务端文档 ID（可为空）和草稿状态。点击完成在安全原图门槛满足后冻结页面集合与顺序，立即返回首页，后台继续生成派生图、上传与处理。独立整理页不再参与生产导航。草稿行进入相机；提交后进入只读进度/文档页，不支持编辑。

## 状态与本机移除

草稿身份与执行进度独立。未关联服务端或连接失败时明确显示“未连接”，不以“上传中/处理中”掩盖离线；本地文件或协议的阻断错误仍显示失败。缓存的已完成文档离线仍可查看。仍有未上传页面时蓝色“上传中”优先于正常 OCR 进度；全部上传后，有实际处理工作才显示黄色“处理中”。绿色“已完成”，红色提示阻断错误；未接入服务、仅本地 READY、退出相机均不意味着 OCR 或 VLM 正在运行。服务端 `flag` 经独立展示模型映射，具体字段和流式 block 协议不在此编造。

左滑只露出删除按钮，点击后确认；长按多选、批量删除同样确认，返回先退出多选。确认文案：“仅从本机列表移除，后台上传和处理仍会继续。”移除只持久化隐藏标记，不删除远端任务、不取消已安排工作，也不清理后台所需图片。重启及后续同步不能让隐藏任务重新出现。此行为与拍摄期间删除某张候选照片不同。

## 数据与联调边界

每个任务独立持有页面清单、图片目录、服务端文档 ID、提交的有序页面快照和上传确认；本机任务身份只是内部索引。旧 `files/scan_draft` 草稿无损纳入任务列表，继续使用其原目录，不触碰 `files/captures`。旧重拍占位转为可删除的失败页，不恢复重拍功能。

上传载荷固定为长边不超过 1280 像素的压缩 JPEG 派生图。逐页上传成功后由服务端排 OCR。最终页序只取用户提交的快照；服务端等引用页面有效 OCR 齐备后才启动组装。没有重拍不意味着可以取消上传幂等：重试仍应复用同一任务、页面身份。页面身份、路径及状态仍不进入公开 C2D-XML。

当前仓库没有服务端业务 HTTP API。经用户授权由 Android 起草 [v1 联调协议](android_task_protocol.md)，实现对应客户端与 WorkManager 调度；服务地址默认留空，此时允许本地拍摄并显示未连接，预览及测试假服务不接入正式新建。协议由客户端提议，不代表服务端已经支持；流式 block 保留为下一阶段扩展，首版读取状态快照和最终只读文本。

## 验证清单

- 空列表、多任务、搜索、左滑确认、多选返回和批量移除。
- 多草稿隔离与恢复、旧草稿保留、隐藏标记重启不丢失。
- 服务未配置、网络断开或创建请求失败时仍可新建和续拍，持续提示未连接；多个离线草稿不复用同一本地身份。
- 离线完成后保留页序和原图，恢复连接并关联真实文档 ID 后再上传、finalize；创建响应丢失时复用幂等键。
- 保存与完成分开，完成冻结页序且不等待上传；提交任务只读。
- 草稿与上传进度并存、上传优先、失败、最终标题和字数更新。
- 长标题、大字及窄屏下元信息保持单行。
- 隐藏任务继续后台执行，切换/新建不清理其他任务图片。

## 本轮实现记录

2026-09-05 离线修订替代“必须在线取得文档 ID 才能打开相机”的首版规则，目的是在服务端协议尚未接入时允许真实拍摄和本地 UI 验证。相机提示采用覆盖层，不占据取景区布局空间；设备无默认网络、任务无服务端 ID 或请求连接失败时显示未连接。设备网络可用本身不代表服务已响应，实际上传和 flag 仍以协议响应为准。网络变化监听依据 [Android 网络状态文档](https://developer.android.com/develop/connectivity/network-ops/reading-network-state)，调度继续由 WorkManager 承担。

服务地址为空时不反复安排无意义请求；配置后重新打开 App，未绑定任务首次记录端点，再后台幂等关联服务端 ID。临时请求失败使用独立 connectionIssue，保留已有页面、提交快照及 OCR/结果事实；协议或本地文件错误仍明确显示，不以未连接掩盖失败。此行为不代表真实服务端联调已经通过。

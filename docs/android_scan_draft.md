# Android 扫描草稿与恢复说明

> 最近修订：2026-09-05。已迁移多任务隔离与任务首页；2026-09-05 用户确认离线版本真机人工测试通过，进程恢复专项和真实服务端联调仍待验收。
> 交互见 [任务首页](android_task_home.md)，网络边界见 [协议提案](android_task_protocol.md)。

## 草稿文件结构

- 全局任务索引：`files/document_tasks/tasks.json`。
- 新任务页面清单：`files/document_tasks/<taskId>/scan_draft/draft.json`。
- 新任务图片：`files/document_tasks/<taskId>/scan_draft/pages/<pageId>/original.jpg` 和 `normalized_1280.jpg`。
- 旧单草稿原地登记为 legacy 任务，仍读取 `files/scan_draft`，不搬动或删除图片。
- 旧相机探针 `files/captures` 不导入、不清理。

任务索引与各页面清单分别用 AtomicFile + 平台 org.json 写入，Mutex + Dispatchers.IO 串行修改并暴露只读 StateFlow。任务页面数由页面清单恢复，跨清单中断不依赖过期显示缓存。删除首页任务只写 hidden；不清理任务目录。

## 两层事实模型

ScanDraft 的 schemaVersion、draftId、创建/更新时间与 pages 保持兼容。ScanPage 保存 pageId、原图和派生图相对路径、状态和错误；数组位置是唯一采集页序，不再提供重拍。

DocumentTask 保存 taskId、服务端 documentId、首次绑定的非空服务端地址（未配置可为空）、创建时间、标题、页面 ID 列表、上传确认集合、submittedPageIds 快照、提交接受标记、文档/页面远端阶段、最终字数和只读文本、错误与 hidden。submittedPageIds 为 null 表示草稿；否则是不可编辑的提交意图，不能把它与远端已接受混为一谈。

新建先持久化独立 clientTaskId 后即进入相机，未连接时持续提示；每个离线任务均可见、可续拍，不复用其他未关联任务。后台使用同一任务幂等键关联真实服务端 ID，落盘后才上传。旧草稿也允许离线续拍。任务清单额外保存可选 connectionIssue，缺少此字段的旧清单仍可读取；网络问题不覆盖本地文件错误。空草稿仍保留文档身份，可保存和继续拍摄，但禁止提交空文档。

## 页面状态与恢复

- CAPTURING：快门已接受并写入占位，原图尚未安全保存。
- NORMALIZING：安全原图已经落盘，正在生成派生图。
- READY：本地图像处理完成，不表示上传或 OCR 成功。
- FAILED：原图/派生图失败，占位仍保持原位置，允许删除后新增照片。
- RETAKE_REQUIRED：仅为读取旧清单保留；恢复时转为 FAILED，生产代码不再产生该状态或提供重拍。

原图与派生图均有效时恢复 READY；只有原图有效时重新归一化；原图无效时保留失败占位，不重放真实快门。有效性要求受限尺寸的真实像素解码，不只检查文件头。

任务仓库严格模式下清单损坏或清单缺失但已有图片时保留文件并显示错误，不覆盖为新空草稿。首页索引损坏也拒绝新写，避免静默遗失全部任务。已被页面清单排除的孤立页面目录才允许清理。

候选优先 postview、原图、派生图；恢复后没有 postview。照片以相同文件和 pageId 参与上传重试，不能把本地路径传给服务端，也不加入 C2D-XML。

## 后台同步与提交

每个任务独立仓库和相机 ViewModel，切换任务不改变旧任务引用。后台观察本地页清单；无配置时只保存本地数据，不反复排空请求。配置服务后先以 taskId 幂等关联并持久化真实 documentId，派生图 READY 后才上传。确认后持久化 uploadedPageIds；网络失败保留图片。

完成时检查所有保留页面有安全原图，再持久化当前有序 ID 快照；UI 回首页，派生图及上传继续。后台只有在快照的全部页面上传确认后才发送 finalize，确认单独落盘。GET 状态获取文档和逐页 flag，最终文档成功后才展示字数。

相同任务的同步串行执行，WorkManager 使用网络约束与指数退避，隐藏不会取消任务。进程重建恢复任务索引与文件，重新读取/提交仍使用原身份。平台调度可延迟；实际网络、进程死亡及服务端幂等联调尚未验收。

## 删除与保存

相机候选删除先更新页清单，再删除该页目录；晚到的拍摄/归一化结果不得重新插入。已上传候选被删除后，其远端结果不在最终快照中使用。

首页左滑或多选删除先确认，随后只持久化 hidden，后台工作和文件保留。保存草稿则回首页保留可见草稿、本地任务 ID 和已有的服务端文档 ID；离线未关联时 documentId 仍为空。已提交任务仅提供只读内容和重新同步，不提供页面编辑。

## 验证范围

JVM 覆盖任务状态、JSON 往返/非法清单与 HTTP 请求契约。设备测试覆盖多个任务同名页面隔离、旧草稿迁移、空草稿、隐藏后继续上传、冻结 C/A 页序、上传失败恢复和不重放快门。设备测试 APK 构建不等于设备执行；结果见 [任务首页实现记录](android_task_home.md#本轮实现记录)。

- Qwen3.5-9B，fp8_per_channel，16K context、8K 最大输出、640 MiB KV cache、单请求、thinking 关闭。硬件 RTX 4070 Ti SUPER，vLLM 0.28.0。
- 照片、完整正文、原始模型响应和本机绝对路径不提交 Git。可交付的完整 JSON/XML/逐块报告保存在本地与 WSL 的 `.cache/documents/`。

### 3. V2 JSON Schema 基线：协议成功，视觉质量仍需改进

提交 `7e4fdf1`，目录 `image-test-group-1-v2-schema-20260905/result`。八张完整处理，耗时 463.94 s，输出 64 块，全部 ok，无 fallback、unresolved 或自然触发的修复调用。各图块数为 5、4、9、8、7、16、8、7。八次 prompt 计数与实际 usage 相符，显存清理通过。完成后的 resume 耗时 0.15 s，没有新增模型调用或重复提交，XML 哈希不变。

相比普通 JSON 基线，四张整图协议降级消失；本次单次运行耗时减少 26.0%，不能据此推断稳定吞吐提升。64 块中有 18 个 b，仍没有颜色 span。视觉复核发现右侧频谱图和数据流步骤仍遗漏、代码缩进仍丢失、部分算术符号误识别，image-7/8 及非相邻图片的重叠正文重复。`needs_review=false` 只代表自动诊断未触发；`semantic_fidelity_verified=false`，不是人工质量验收。

独立故障注入 `image-test-group-1-repair-probe-20260905` 将一个真实 pre 放入非法 blockquote；模型一次修复将其拆成三块，同时复制了旁边已经通过的段落和表格。四个正常邻居本身没有被修改，但最终由五块变七块，出现重复。该注入不能计入八图自然错误率。

## 后续五轮迭代

以上两次 V2 八图运行作为基线，不计入此后的五轮。每轮使用独立输出目录，保留原始请求、响应、草稿、错误、提交状态与逐块报告；复用身份和配置一致的 OCR。视觉锚点由原图人工审阅建立，抽样检查内容、强调样式与重叠，标签数量不作为正确率。

### 第 1 轮：结构修复保护内容与旧尾块

针对真实故障注入发现的重复，在替换草稿之前检查整个目标组的文字、顺序和重复次数；保护失败块独立保存的文字，并单独保护代码空白。拒绝删字、扩写、复制邻居的 patch，保留原草稿与已消耗预算。旧尾块必须完整位于第一个替换块开头；不可分辨新增后缀时禁用 OCR 兜底，避免把旧尾再次插入正文。

提交 `7fef03c`，目录 `image-test-group-1-iteration-1-20260905/result`。保持主生成提示词和模型参数不变。八图回归 8/8 完成，63 块全部 ok，没有自然修复，耗时 446.52 s；实际 token 计数及 GPU 清理验证通过。主生成的块数和标签数有单次运行差异，不能归因于仅作用在修复路径的改动。

相同故障注入在独立 `image-test-group-1-iteration-1-probe-20260905/result` 中完成，耗时 308.41 s。五次响应均因 `REPAIR_CONTENT_CHANGED` 被拒绝：第一次复制邻居，之后又增加“代码块”等范围外文字。最终保留 4 个 ok 邻居和 1 个 OCR fallback，不再复制旁边段落/表格。结论是门禁有效，模型仍未学会在正确范围内修复，不能把局部兜底统计为 VLM 修复成功。

启动器曾同时启动两个 CLI，八图任务被非阻塞 GPU 锁拒绝，尚未发出模型请求；保留该记录，并在注入完成后自动 resume 八图。上述八图耗时不含等待与被拒绝的启动。后续显式串行调度测试。

### 第 2 轮：整图区域检查、单份 OCR 与独立文字遗漏检测

基于右栏遗漏、错误转录和真实注入重试反馈，主提示要求检查全部图片区域；OCR 只发送一份带来源标识的文本，不再同时重复发送原文。明确 OCR 正常结束不意味着图中内容全部识别。修复模式明确只处理 targets，不执行主生成的整图转录要求。

合法 XML 的文字如果是独立 text 的真子串，且丢失至少 8 个非空白字符，则进入局部修复；错误包括遗漏前后文、位置、允许结构和经校验的通用示例。反向的“XML 完整但 text 短摘要”、代码控制标签等不确定差异只保存诊断，不据此缩短正文。离线重放基线 64 个候选，仅检测到 image-2 的标题丢失引导句，其余没有被误判为遗漏。

新增 `scripts/evaluate_document.py` 验证检查点、导出、真实 token 和清理记录，并支持固定的人工视觉抽样锚点。它报告原始候选的文字差异和重复，不修改结果，不把抽样覆盖率当全文正确率。

提交 `3c43c5a`，目录 `image-test-group-1-iteration-2-20260905/result`。8/8 完成，58 块全部 ok，零自然修复，耗时 431.53 s，实际 token 与清理验证通过。固定 49 项抽样从 R1 的 9/49 提升到 17/49：内容 13/20、标题及粗体 4/21、背景高亮 0/6、蓝字 0/2。两个右侧区域的 8 项锚点全部恢复，运算符仍 0/3；不能宣称逐字转录已正确。独立修复注入仍是 5 次失败后局部兜底（4 ok + 1 fallback），耗时 214.62 s，范围提示尚未解决该问题。

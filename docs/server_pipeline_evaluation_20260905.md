## 输入载荷与分辨率诊断

原始八份 JPEG 文件各约 4–5 MB，但主图 JPEG 的 SOF 尺寸与完整解码结果均为 800×600；服务端没有从一个 4000×3000 JPEG 中误选 EXIF 缩略图。逐个扫描并验证 JPEG 起止标记后，每份载荷只发现 800×600 主 JPEG 和 200×150 附加 JPEG，没有可完整解码的更高分辨率 JPEG。EXIF 均仍声明 4000×3000，与实际主图不一致，不能据此认为这些静态像素仍然存在。

文件体积主要来自主 JPEG 结束标记之后的两段 HEVC 视频。每份主 JPEG 只有 194,839–274,313 字节，占文件的 4.02%–5.24%；两段 MP4 的编码尺寸分别为 1440×1080 和 1312×984。实际解码全部 16 段视频后，均得到对应尺寸的帧，因此更高分辨率视频像素的存在已经验证。所有原始文件 SHA 在调查前后保持不变，报告只记录格式、尺寸、字节范围与校验信息，不记录设备、位置或作者元信息。

随后从每张图片的第一段视频保存一个中间时刻的 1440×1080 PNG，逐张与原始 800×600 主图对照。八组均高置信对应同一文档区域，未见滚页；有轻微拍摄位置差异，字迹、粗体和局部高亮更容易人工辨认，未见新增明显运动模糊。摩尔纹、反光及边缘裁切仍存在，视频与静态照片还可能具有不同的曝光和显色。候选、精确来源范围、实际时刻和 PNG SHA 保存在 ignored 的 `highres-candidates/manifest.json`；文件载荷调查保存在 `image-payload-audit.json`。

这些候选没有替换五轮主链路输入，也没有作为八图主链路测试运行。视觉上更清楚不等于 OCR/VLM 结果必然更准确。若开展对照，应使用独立输入清单、检查点和重新计算的 OCR，保留原始 800×600 基线，不能复用不同图片字节对应的旧 OCR。

独立样式诊断对 image-5 的原始 800×600 PNG 和同区域 1440×1080 帧各调用 Qwen 一次，只返回样式短语、粗体、前景与背景颜色，不生成 C2D 正文。两次请求分别耗时 10.66 s、9.09 s，实际 prompt 计数与预检一致，GPU 清理通过。逐条复核全部 22 个 marks：原图任务仍漏掉局部粗体和底色，并标注普通灰字；高分辨率帧识别到 Gemini/Qwen 比较短语的真实暖底色，同时给无底色的 9B、12GB 片段添加 orange，并将暖色强调误判为 blue。两个输入均只识别标题粗体，正文 marks 的 bold 全为 false。重复出现的短语还没有 block/occurrence 定位，不能安全叠入正文。因此这两次调用只作诊断，未增加到主链路，也不计为一轮八图测试。

## 下一轮具体优化与验收

1. 扩展经过校验的结构选项到 `ONE_BLOCK_REQUIRED`：仅当原 XML 的多个顶层根均合法、拆分后的整体文字与独立 text 可证明一致时，提供按原顺序拆分的选项；列表符号、代码空白或文字不一致时继续保留原稿，不强行拆分。用第 5 轮自然失败草稿重放，目标是一次选择修复且正确邻居及全文不变，再做完整八图回归。
2. 先验证输入像素再优化样式。修正采集/压缩链路对实际解码尺寸的检查，避免大文件、陈旧 EXIF 和视频载荷掩盖 800×600 静态图。用独立清单比较原静态图与更清晰的同区域输入，重新计算 OCR；模型参数保持一致。除了既有锚点，增加数字、运算符、代码缩进的逐项真值。
3. 样式实验只改已冻结文字的明确范围：返回 block ID、具体出现位置和字符区间，程序验证文字不变及 C2D 嵌套规则，区分前景与背景并统计误加样式。先验证局部裁切输入能否识别粗体与高亮；当前两次短任务仍漏正文粗体、有假高亮，尚不能直接自动叠加到最终正文。
4. 将跨图拼接移到独立判定阶段，避免主转录同时生成当前内容和重写历史。保留完整当前候选，与较短历史及实际图像证据作只读比较；不确定时保留并待复核。离线检索实验中，要求正文至少 40 字、连续匹配至少 24 字、匹配率至少 60%，消除了 R1/R2 的两次无关召回且保留四次已知重叠查询；这只是 8 个查询的离线结果，不能修复已经证实的最近历史污染，也不授权直接删文。

## 评价边界

- 固定 49 项是人工确认的有限样本：内容 20 项、标题及粗体 21 项、背景高亮 6 项、蓝字 2 项。标题与源图正文粗体另有分类；检查器允许语义标题满足粗体条件，分类不能证明输出仍保持原来的段落层级。
- 内容 20 项中，右侧区域 8 项、运算符 3 项、其他内容 4 项、重叠唯一性 5 项。每项统计命中的最终 block 数，同一 block 内多次出现同一词只计一个命中，不能检测所有块内重复。
- 右区锚点全部通过也不代表图示完整。例如 R2 与 R3 都没有保留频谱图中的条形几何；这些条形不属于当前八项文字锚点。列表嵌套、代码缩进、表格各单元格和整段逐字准确性仍需独立检查。
- 8/8 处理完成、全部 block 为 ok、XML 校验通过，均不等于八张内容完整或语义正确。原始 OCR 自己遗漏的区域也不能用 OCR 字符对齐证明完整。
- 单次运行耗时、标签计数与有限样本分数只支持相应实验的观察。故障注入、短任务探针和输入载荷调查应分别记录，不计为八图自然修复或额外一轮主链路成功。

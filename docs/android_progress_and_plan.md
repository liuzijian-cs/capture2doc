## 设计演变与被替代的方案

旧方案只在本节作为演变依据保留，不再以“当前实现”描述旧网格或单草稿。早期总体架构已提增量上传，但曾要求先接受页面并把排序交给服务端；Android 阶段计划则曾采用“整理页 → 本地单草稿”，讨论中也出现过整理后统一上传。

| 主题 | 已被替代的方案 | 当前有效规则与实施状态 |
|---|---|---|
| 新建门槛 | 必须先在线取得文档 ID 才能进相机 | 先落盘独立 taskId 即可拍摄，未连接持续提示；后台取得真实 documentId 后才上传，人工冒烟按用户确认通过 |
| 相机与整理 | 完成进入独立网格，随后保存 | 相机承担候选管理；完成冻结最终页序并回任务首页；网格代码已移除 |
| 上传时机 | 整理后统一上传 / 每页需单独接受 | 真实文档 ID 和 1280 JPEG 派生图就绪后逐页幂等上传；客户端已实现，服务端 HTTP 待接入 |
| OCR 与组装 | 上传、最终确认和模型启动边界不清 | 服务端接收即排 OCR；最终提交接受且引用结果齐备后才 VLM 组装，不按回调顺序 |
| 页序 | 服务端或 VLM 决定页面排序 | 用户完成时冻结的有序页面 ID 列表是唯一最终页序 |
| 完成含义 | 只导航 / 此时才首次生成草稿 | 自动保存页面事实；完成冻结本地快照并回首页，可早于上传；后台补传齐备再调用会话 finalize，不等于 XML finalize |
| 草稿与存储 | 单草稿；曾考虑用 SavedStateHandle 存页面事实 | 多任务私有目录 + AtomicFile JSON；SavedStateHandle 只存导航；WorkManager 负责网络后台，不引入 Room/DataStore |
| 删除 | 网格两步删除叉 / 放弃整个草稿清理全部文件 | 候选和大图双击删除单页；首页确认后仅 hidden，后台和所需文件保留 |
| 重拍 | 原位置、同 ID 替换旧照片 | 入口与实现移除；删除旧页后新增照片获得新 ID；旧 RETAKE_REQUIRED 仅恢复兼容为失败 |
| 保存与空草稿 | 保存后清理空草稿，或所有草稿都从未上传 | 保存保留可续拍本地任务及已有关联；允许空草稿保存、禁止空提交；草稿可已开始联网处理 |
| 恢复 | 不恢复拍摄中进程死亡 / 只恢复单草稿 | 按任务恢复已落盘文件，不重放快门；上传确认、快照、hidden 已持久化，网络及杀进程专项未验收 |
| 主题 | 全 App 随系统黑蓝浅深色 | 普通业务页固定蓝白，仅相机固定蓝黑；关闭动态配色，颜色不影响 XML/Renderer |

## 当前本地功能细节

相机使用真实 JPEG，不将预览截图作为原图；请求约 5MP、4:3，设备实际输出由 CameraX 决定。EXIF 旋正与长边 1280 派生图在后台完成。最多接受 3 个尚未完成原图落盘的任务，安全原图落盘后释放名额，归一化串行执行。1280 像素与模型的 1280 image tokens 是不同概念。

相机取景框不受候选数目影响。竖屏 3:4、横屏 4:3；黑色剩余区域与覆盖层共同承载控件。快门在底部中央，完成按钮在右侧，圆角方形候选横排在快门上方。顶部操作只留返回，未连接时另有不挤压取景区的提示浮层，不再展示“相机能力测试”“已拍 N 张”“保存中”或性能数据。内部诊断仍可用于开发。

### 编辑和返回矩阵

| 所在位置 | 当前操作与返回 |
|---|---|
| 任务首页 | 标题搜索；草稿点击续拍，已提交任务进入只读详情；左滑/多选删除均确认后只隐藏 |
| 相机候选条 | 单击大图、双击永久删除、长按拖拽松手持久化；不支持重拍 |
| 相机候选大图 | 单页预览、双击删除，返回相机；没有旧网格 Pager |
| 相机返回 | 保存并退出 / 仅从本机列表移除 / 继续拍摄；已接受的原图尚未安全落盘时等待 |
| 相机完成 | 至少一页且保留页原图安全；冻结最终集合与顺序并回首页，不等待联网或 OCR |
| 提交后的详情 | 展示真实阶段或缓存最终文本，不再编辑页面；离线不清除已缓存结果 |

删除最后一页保留可续拍的空草稿，允许保存退出但不能提交空文档。文件恢复按实际解码判定：有效原图和派生图恢复 READY；只有原图则重建派生图；原图无效保留失败占位。旧重拍状态仅兼容为 FAILED，不恢复重拍功能。丢失内存 postview 不等于丢失照片。详情见 [草稿恢复](android_scan_draft.md) 和 [相机架构](android_camera_architecture.md)。

### 主题与原型设计

黑、白、中性灰和蓝构成主体，参考简洁的对话产品信息层级。蓝色使用 `#5595D1 / #A9C9FF`；红色 `#E97A7A / #FFBEC2`；黄色 `#E5C679 / #FFEEBC`；绿色 `#55967E / #B4DBCA`。完整 Material 3 与状态色映射集中在 [Android 视觉主题](android_app.md#android-视觉主题基线)。

本轮已关闭动态配色，但“映射完成”不代表所有前景背景组合已经通过可读性检查。尤其现有中性蓝灰深色容器搭配近黑前景需在 UI 原型评审中检查；本次仅记录现状，不调整颜色代码。

Android Studio 可以使用现有任务首页和相机 Preview 比较空态、多任务、离线提示、处理中与失败；旧整理页 Preview 已随组件移除。用户已部署当前离线版本并确认人工测试通过；预览不会调用真实相机、持久草稿或服务器。具体步骤见 [原型预览](android_env.md#android-studio-原型预览) 和 [真机部署](android_env.md#通过-android-studio-部署)。本地 UI 不依赖 Gradio；Gradio 已启动不等于 Android 已联通 OCR 服务。
